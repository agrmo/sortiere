## heapsort

A proper implementation of heapsort using a min-heap. Runs in `2*n*log(n) = O(nlogn)` time, `nlogn` for the upheaping, `nlogn` for the downheaping. e.g.

```
[9, 5, 1, -1, 51, 521, 19, 2, 6, 111]
```

returns

```
[-1, 1, 2, 5, 6, 9, 19, 51, 111, 521]
```
